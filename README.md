# claude-skill-aspro

Портативный скилл для Claude Code по интеграции с **Aspro CRM**.
Содержит официальную OpenAPI-спеку, поисковый скрипт по ней и набор
реальных граблей, которые легко поймать при работе с API Aspro.

## Зачем это нужно

Aspro CRM — российский B2B CRM с большим, но местами очень
«неочевидным» REST API: 622 эндпоинта, POST как form-urlencoded
(не JSON), кастомные поля в двух форматах сразу, внутренние ID
валют (не ISO 4217), и ещё десяток ловушек.

Скилл сжимает это знание в один пакет: установил → твой Claude
теперь знает все типовые грабли и не выдумывает имена полей по
памяти.

## Установка

```bash
git clone https://github.com/Pirus2302/claude-skill-aspro \
  ~/.claude/skills/aspro-integration
```

После этого открой любой свой проект в Claude Code — скилл подхватится
автоматически и активируется по триггерам «Aspro», «aspro»,
«customer_payment», «вебхук CRM» и т.п. (см. поле `description` в
`SKILL.md`).

## Что внутри

| Файл | Назначение |
|---|---|
| `SKILL.md` | Главный документ — 10 ключевых граблей, типовые сценарии, базовый URL. |
| `openapiru.json` | Официальная OpenAPI-спека Aspro (622 эндпоинта, ~4 МБ). |
| `scripts/lookup_endpoint.py` | Поиск по спеке без загрузки её целиком в контекст. |
| `docs/webhook-setup.md` | Настройка вебхуков с двумя рубежами защиты (токен в URL + X-Aspro-Secret). |
| `examples/python-client.md` | Эталонный Python-клиент: rate-limit, retry, пагинация. |
| `examples/typescript-client.md` | Эталонный TypeScript-клиент на axios с interceptor для retry. |

## Пример использования

После установки попроси Claude:

> «Помоги принять платёж в Aspro через customer_payment»

Claude автоматически:
1. Загрузит `SKILL.md` (потому что слово «Aspro»).
2. Предупредит про form-urlencoded (не JSON).
3. Предупредит про currency_id (не ISO 4217).
4. Предупредит про cf_ + cf. для кастомных полей.
5. Перед написанием кода вызовет `lookup_endpoint.py customer_payment`
   чтобы свериться с реальной схемой.

## Совместимость

- **Claude Code** (CLI и desktop) — основной таргет.
- Требует Python 3 для `lookup_endpoint.py` (стандартная библиотека,
  никаких зависимостей).
- Спека `openapiru.json` — состояние Aspro API на момент сборки.
  Aspro расширяет API — спека может устаревать. Скачать свежую можно
  с официальной документации Aspro.

## Безопасность

- Внутри `openapiru.json` есть **иллюстративный** `api_key=` из доков
  Aspro — это не рабочий ключ. **Никогда не копируй его в свой код.**
- Свой рабочий ключ держи только в env-переменной (`ASPRO_API_KEY`)
  и не коммить в репозитории.
